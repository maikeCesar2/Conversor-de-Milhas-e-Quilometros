# Conversor de Milhas e Quilômetros

Aplicação web simples que converte distâncias entre milhas e quilômetros.

## Funcionalidades

- Converte milhas para quilômetros
- Converte quilômetros para milhas
- Resultado exibido na hora, direto na página

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

1. Baixe ou clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Digite o valor, escolha a conversão e veja o resultado
